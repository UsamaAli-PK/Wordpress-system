# Playbooks & Workflows

Actionable procedures for reverse-engineering third-party WordPress themes/plugins, extracting components cleanly, and assembling unified Elementor-compatible systems.

## Playbooks

1. [01. Reverse-Engineering & Codebase Audit Protocol](file:///root/Desktop/learn/BAse/playbooks/01-reverse-engineer-audit.md) — Read-only static inspection, search patterns, dependency mapping, and Component Manifest generation.
2. [02. Decoupling, Isolation, and Migration Protocol](file:///root/Desktop/learn/BAse/playbooks/02-extract-isolate-merge.md) — Stripping proprietary option frameworks (Redux/Kirki), strict namespacing, asset isolation, and modern PHP/API upgrades.
3. [03. Converting Extracted Sections to Elementor Widgets](file:///root/Desktop/learn/BAse/playbooks/03-section-to-elementor-widget.md) — DOM parity preservation, control mapping, repeater setup, and re-wiring JS to Elementor frontend handlers.
4. [04. Unified Theme and Companion Plugin Assembly Workflow](file:///root/Desktop/learn/BAse/playbooks/04-build-unified-theme.md) — End-to-end assembly of custom base themes, companion plugins, CSS variables bridge, and preflight quality gates.
